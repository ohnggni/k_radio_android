## 1.0.2 (2026-09-25)

### 새 기능
- 업데이트 알림: 새 버전이 있으면 상단 배너 아래에 안내 카드 (나중에를 누르면 그 버전은 숨김)
- 설정에 앱 정보: 현재 버전과 다운로드 폴더 바로가기
- 채널 로고를 앱에 내장: 바로 뜨고 인터넷 없이도 표시
- 워치 재생 목록에 재생 중인 채널뿐 아니라 모든 채널의 지금 프로그램 표시
- 재생 중인 채널 로고를 이미지 데이터로 전달해 갤럭시 워치 등에도 표시

### 개선
- 모르는 채널을 받았을 때, 30분마다, 재연결할 때 채널 설정을 다시 받아 방송 주소 변경을 앱 재시작 없이 반영
- 상단 배너와 재생기 모서리를 직선으로

### 데이터
- 채널 1개 추가
- 편성 정보가 없던 채널 2개에 편성표 추가

## 1.0.1 (2026-09-25)

### 새 기능
- 알림, 잠금화면, 갤럭시 워치, 블루투스 차량 화면에 지금 방송 중인 프로그램 표시 (제목은 채널명, 부제는 프로그램). 매분과 채널 변경 때 재생을 끊지 않고 갱신

## 1.0.0 (2026-09-25)

첫 배포

### 재생
- 화면이 꺼지거나 앱을 닫아도 계속 재생
- 기본 라디오 채널 16개
- 재생 직전에 기기에서 방송 주소를 확인 (접속마다 주소가 바뀌는 채널 포함). 별도 중계 서버 불필요
- 알림, 잠금화면, 블루투스 기기, 갤럭시 워치에서 이전·다음 채널 (워치 재생 목록에서 채널 선택 포함)
- 앱이 꺼져 있어도 블루투스 재생 버튼으로 마지막 채널 재생
- 끊기면 점점 간격을 늘려 자동 재연결(1초 → 30초), 네트워크가 돌아오면 바로 재연결, 재시도마다 방송 주소를 새로 확인

### 화면
- 메인 화면: 로고가 있는 채널 목록, 지금 프로그램과 방송 시간, 재생기, 날짜·시각 상단 배너
- 5분 미만의 짧은 편성(날씨, 캠페인)은 건너뛰고 앞뒤 본 프로그램 표시
- 채널 관리: 끌어서 순서 변경, 표시·숨김, 내 채널 추가(HLS, MP3, AAC), 모든 채널의 이름·주소·로고 수정, 채널별·전체 초기화
- 설정: 채널 설정과 편성표 출처 지정, 기본값 복원, 연결할 수 없을 때 경고 카드
- 앱 안에 데이터 형식 안내와 복사할 수 있는 예시

### 데이터
- 채널 설정과 편성표는 인터넷에서 받아 기기에 저장, 인터넷이 없으면 저장본 사용
